/UI-UX-PRO-MAX
Hãy đóng vai một Chuyên gia UI/UX và Lập trình viên Frontend cấp cao. Hãy viết lại toàn bộ file `index.html` cho dự án "Web-based Video Downloader" của tôi.

1. BỐI CẢNH DỰ ÁN:
- Backend: FastAPI + yt-dlp + WebSockets.
- Endpoint 1 (Lấy thông tin): POST `/api/info`. Body: `{"url": "string"}`. Trả về: `{"title": "string", "formats": [{"id": "string", "label": "string"}]}`.
- Endpoint 2 (Tải video): POST `/api/download`. Body: `{"url": "string", "format_id": "string"}`.
- WebSocket URL: `ws://127.0.0.1:8000/ws`.

2. YÊU CẦU GIAO DIỆN (BẮT BUỘC PHẢI CÓ ĐỦ CÁC ID NÀY):
- Ô nhập link: `id="urlInput"` (Placeholder: "Dán link video YouTube, TikTok, Playlist...").
- Dropdown chọn chất lượng: `id="formatSelect"` (Mặc định ẩn `display: none`).
- Nút Tải xuống: `id="downloadBtn"` (Text: "Tải Xuống").
- Khung tiến trình (Mặc định ẩn): `id="progressContainer"`. Bên trong gồm:
  + Thanh Progress: `id="progressBar"` (max=100, value=0).
  + Text phần trăm: `id="percentText"` (Mặc định: "0%").
  + Text tốc độ: `id="speedText"` (Mặc định: "Đang chờ...").
  + Text trạng thái thành công: `id="statusText"` (Màu xanh lá, mặc định rỗng).
  + Text báo lỗi: `id="errorText"` (Màu đỏ, mặc định rỗng).

3. YÊU CẦU LOGIC JAVASCRIPT (VIẾT BẰNG ES6):
- Sự kiện 1 (Lấy Info): Khi người dùng nhập link vào `urlInput` và click ra ngoài (sự kiện `blur`), tự động gọi fetch POST `/api/info`. 
  + Nếu thành công: Đổ dữ liệu vào `formatSelect` (value=id, text=label), sau đó hiển thị `formatSelect`. Nếu lỗi, hiển thị lỗi ra `errorText`.
- Sự kiện 2 (Tải xuống): Khi click `downloadBtn`, gọi fetch POST `/api/download` với `{url: urlInput.value, format_id: formatSelect.value}`. Đồng thời:
  + Disable nút Tải (đổi màu xám, text "Đang xử lý...").
  + Hiển thị `progressContainer`, reset thanh bar về 0, xóa các text lỗi/thành công cũ.
- Sự kiện 3 (WebSocket): Khởi tạo kết nối tới `ws://127.0.0.1:8000/ws`.
  + Khi nhận `data.status === "downloading"`: Cập nhật value cho `progressBar`, text cho `percentText` và `speedText`.
  + Khi nhận `data.status === "finished"`: Đẩy `progressBar` lên 100%, hiện thông báo thành công xanh lá ở `statusText`, ẩn speed, Enable lại nút Tải.
  + Khi nhận `data.status === "error"`: Hiện `data.message` màu đỏ ở `errorText`, Enable lại nút Tải.

4. PHONG CÁCH THIẾT KẾ (UI/UX):
- Phong cách chủ đạo: Modern Dark Mode (Giao diện tối) kết hợp Glassmorphism (hiệu ứng kính mờ cho khung chứa).
- Màu sắc: Nền tối (Slate-900), Nút bấm dùng Gradient từ Xanh dương sang Tím. Chữ màu trắng/xám nhạt. Lỗi dùng màu đỏ tươi, Thành công dùng màu xanh ngọc.
- Typography: Dùng font Inter hoặc Roboto qua Google Fonts. Chữ to, rõ ràng, dễ đọc.
- Layout: Căn giữa màn hình (Flexbox/Grid), responsive tốt trên cả Mobile và Desktop.
- Sử dụng Tailwind CSS qua CDN để code gọn và đẹp nhất.

5. YÊU CẦU KỸ THUẬT:
- Chỉ trả về 1 file HTML duy nhất chứa toàn bộ (HTML, CSS, JS).
- Code JS phải sạch, có try-catch khi gọi fetch để bắt lỗi mạng.
